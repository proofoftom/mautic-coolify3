# My Page Theme

A custom Mautic page theme example.

## Features
- Page theme for Mautic landing pages
- Simple, clean design
- Responsive layout

## Installation
This theme is automatically installed via the Dockerfile during build.

## Usage
1. Go to Mautic Admin > Configuration > Themes
2. Select "My Page Theme" from the Page Theme dropdown
3. Click Apply

## Customization
Edit the following files to customize:
- `html/page.html.twig` - Main page template
- `html/base.html.twig` - Base template with HTML structure
